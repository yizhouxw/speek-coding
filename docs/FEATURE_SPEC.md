# SpeekCoding 功能规格

SpeekCoding 是 macOS 上的本地优先语音输入工具。用户开始录音时说出内容，结束录音后，应用转写语音并按照所选方式将文字交给当时的前台应用。产品定位和范围见 [PRODUCT.md](PRODUCT.md)。

## 系统与设备

- 支持 macOS 13 及以上版本，安装包按 Apple Silicon（arm64）和 Intel（x86_64）架构提供。Windows 和 Linux 不在当前支持范围内。
- 使用 macOS 可识别的音频输入设备，包括系统默认麦克风、Mac 内置麦克风和已连接的外置麦克风。用户可在菜单栏选择设备；新选择从下一次录音生效。已选设备断开时菜单会标记为未连接。
- DJI Mic Mini 接收器可通过 USB-C 连接 Mac，作为外置麦克风使用。配置键盘加 DJI 触发方式后，也可使用发射器的连接键控制录音。其他麦克风的硬件按键不保证可用。
- Fn 和 DJI 按键触发依赖单独安装和授权的 Karabiner-Elements。应用需要麦克风权限；自动粘贴和发送还需要相应的辅助功能和事件发送权限。

## 触发、录音与取消

- 用户可选择单独按 Fn 键触发，或配置 Fn 加 DJI Mic Mini 连接键触发；也可使用 `speek trigger`。Fn 与其他按键组合时保留系统及应用的原有行为，不触发录音。第一次触发开始录音，再次触发停止录音并开始转写。
- 录音最长持续 5 分钟；超时后自动取消并删除本次录音。
- 录音和转写期间，用户可点击悬浮窗中的 Cancel 按钮或运行 `speek cancel` 取消当前操作；转写期间再次按触发键也可取消。
- 取消录音或转写会清理本次临时录音，不交付转写结果。用户也可使用 `speek test-record` 检查麦克风，该测试可保留指定的录音文件。

## 转写

- 默认使用本机 faster-whisper 和 `whisper-large-v3-turbo` 模型，支持中英文混合口述和代码相关词汇。安装包包含本地运行时，首次使用模型时需要下载模型权重。
- 可配置本地 whisper.cpp 或 OpenAI-compatible 转写服务。远端服务必须使用 HTTPS；明文 HTTP 仅用于本机 loopback 地址。使用远端服务时音频会发送给该服务。
- 模型下载和加载阶段显示状态；用户可以取消等待。取消下载后，下次转写会重新尝试，已缓存文件可复用。

## 文字交付

转写完成后，应用先将文字复制到剪贴板，并根据设置选择：

- **粘贴并发送**：向录音开始时的前台应用粘贴文字并发送 Return，默认启用。
- **只粘贴**：向该应用粘贴，不发送 Return。
- **只复制**：仅复制到剪贴板，不模拟粘贴或按键。

目标应用需要支持粘贴。录音开始后目标应用若已退出，应用不会自动改投其他窗口。

## 状态与管理

- 菜单栏提供麦克风选择、权限状态与设置、Karabiner-Elements 状态及退出操作。
- 悬浮窗显示录音、转写、模型准备和结果状态；有硬件缺口的屏幕使用贴合缺口的布局，其他屏幕显示顶部居中的悬浮窗。退出应用时关闭悬浮窗；应用进程异常退出时，悬浮窗自行退出。
- `speek status` 和 `speek doctor` 分别提供状态和诊断信息；用户可通过 `speek config` 调整配置。
- 默认录音和转写在本机处理；普通会话的临时录音在结束后清理。应用启动或退出时会相应启动或停止由应用管理的本地转写服务。
