01 / PRIVATE BY DEFAULT

Your voice stays local.

Default transcription uses a service on your own Mac. Models download once; choosing a remote ASR endpoint is optional and sends audio to that provider.

02 / NATIVE INPUT

A tap, then a thought.

Use Fn or a DJI Mic Mini button. No Karabiner installation required. DJI volume-up suppression is scoped to the matched device while native input is active.

03 / YOUR WORKFLOW

From speech to your app.

Dictate in Chinese, English, or both. Choose clipboard delivery, automatic paste, or paste and send. Optional local text correction is available on Apple Silicon.

A SMALL TOOL. LESS FRICTION.

Three steps.
Then keep going.

  1. Install & prepare

    Download the package for your Mac, run speek setup, and prepare a local speech model.

  2. Allow native input

    Grant Microphone and Input Monitoring permissions. Automatic paste needs additional permissions. Set the macOS Fn/Globe action to Do Nothing.

  3. Speak into your workflow

    Tap Fn to start and stop. Review the live transcript and the separate status messages. Use a DJI button if you prefer a physical trigger.

Before you install

Release packages are not Apple-notarized. macOS may block installation or require permissions to be granted again after updates. Quit other remappers that own the input device. Normal exit restores DJI mappings; after a forced termination, recovery runs on the next launch. Sleep/wake and additional hardware combinations still need broader field testing.

Speech and text models have their own licenses. See the release’s license files and support guide.
